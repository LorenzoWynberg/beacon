# Dark mode

The page opens in light or dark to match your device's setting.

- Press the **Dark mode** button in the header (Tab to it, then Enter or Space) to switch. It reads "Dark mode: on" or "Dark mode: off".
- Your choice is saved in this browser and used on later visits, taking priority over the device setting.
- If the browser blocks storage, the button still works until you close the page.
- With JavaScript off, the button is hidden and the device setting applies.
